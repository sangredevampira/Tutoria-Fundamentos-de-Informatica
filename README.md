## 🚀 Recomendaciones de estudio

* Intenta crear una solución para cada ejercicio en papel antes de tocar el compilador
* No copies las soluciones directamente
* Programa con regularidad durante la semana, pero recuerda tomar descansos
* Puedes utilizar la IA como un **apoyo para resolver dudas**, pero sin sustituir la práctica
